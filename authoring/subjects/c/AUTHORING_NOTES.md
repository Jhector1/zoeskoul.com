## Teaching contract

Every algorithmic topic follows: concept and invariant → pseudocode input → worked trace → manual animation → predict next step → guided C → independent C → complexity → edge cases → recap.

C is the executable language. Pseudocode uses `pseudocode_input` with dialect `zoeskoul-v1`; pass/fail is based on normalized IR, semantic structure, and bounded deterministic scenarios. AI may explain a deterministic failure but never decides the grade.

## Cumulative project contract

Every standard module adds files to the same course workspace and ends with one progressive module project. The last module contains one section and one capstone topic. Later steps preserve all earlier tests.
