# Curriculum Draft Source

This directory is the canonical editable source for learner-facing topic content.

- `authoring/` owns catalog, subject, course, module, topic structure and policy only.
- `.curriculum-drafts/` owns editable `TopicAuthoringDraft` JSON, whether written manually or first generated by the compiler.
- `.curriculum-build/` is generated compiler output (manifests, bundles, messages, reports) and must not be edited as source.
- `packages/curriculum-registry/published/` is released production curriculum.

Canonical topic layout:

```text
.curriculum-drafts/<catalog>/subjects/<subject>/courses/<course>/topics/<moduleSlug>/<topicId>.json
```

The compiler uses an existing source draft first. If none exists, generation may create one after the topic passes validation. Once saved, that source draft is reused and is never silently overwritten.
